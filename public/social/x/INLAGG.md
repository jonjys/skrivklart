# X-inlägg för Skrivklart

Ett inlägg om dagen. Lägg upp bilden + texten **utan länk**, och svara sedan direkt på ditt eget inlägg med länken (X visar inlägg med länk för färre). Max 1–2 hashtags.

Liggande bilder (1600×900) för X ligger i den här mappen. Stående (1080×1350) för Threads/TikTok/Instagram ligger i `../v/`.

## Profil
- Profilbild: `profilbild.jpg`
- Banner: `banner.jpg` (1500×500)
- Namn: Skrivklart
- Bio: Brev och avtal på korrekt svenska. Samboavtal, underhåll, Försäkringskassan, inkasso. Gratis utkast, 59–99 kr för hela texten. Inte juridisk rådgivning.
- Webbplats: skrivklart.se
